# Personal Portfolio Website 🌐

Welcome to my personal portfolio website! This is one of my beginner web development projects, created using HTML and CSS.

## 📌 About the Project

This website introduces me as a Web Developer and showcases my interests, projects, and contact information. It contains two webpages linked together for easy navigation.

## 📄 Pages

### 1. Portfolio Page
- Introduction: Mohamed Luqmaan
- About Me section
- My interests
- My projects:
  - Amazon E-commerce Clone using React.js (Front-End)
  - Travel Website
- Social media links
- Navigation to the Contact page

### 2. Contact Page
- Name input field
- Email input field
- Message text area
- Submit button
- Navigation back to the portfolio page

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## ✨ Features

- Two linked webpages
- Custom styling with CSS
- Google Fonts integration
- Contact form interface
- Simple and user-friendly design

## 📂 Project Structure

```text
portfolio-project/
├── portfolio.html

├── style.css
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `portfolio.html` in your web browser.
4. Click the Contact link to visit the contact page.
5. Click Home to return to the portfolio page.
